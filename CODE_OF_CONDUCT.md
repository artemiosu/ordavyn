# Code of Conduct

Project participation must remain respectful, relevant, and safe. Discuss ideas and observed behavior without harassment, threats, discrimination, doxxing, or publication of another person's private information. Do not place credentials, production data, or suspected vulnerability details in public issues.

The repository does not yet identify a private conduct-reporting contact or promise a response time. Until one is established, avoid posting sensitive personal details publicly. Ordinary, non-sensitive moderation concerns may be raised in a repository issue. This limited process is part of the candidate's current experimental status.
