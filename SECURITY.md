# Security policy

Ordavyn is an experimental local candidate, not an approved release, security certification, or production service. No released version is currently supported. See [docs/LOCAL-THREAT-MODEL.md](docs/LOCAL-THREAT-MODEL.md) and [docs/RELEASE-STATUS.md](docs/RELEASE-STATUS.md) for known boundaries.

No verified private vulnerability-reporting channel or response SLA exists yet. Do not put exploit details, credentials, private keys, production data, or personal data in a public issue. If a report can be made safely without sensitive detail, open a minimal issue stating only the affected area and that private coordination is needed. Wait for a real maintainer channel to be published before sending sensitive material.

Repository checks and CodeQL are bounded engineering controls. They do not establish that the candidate is secure or ready for production.
